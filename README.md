# Snapbuild — тестовое задание

Адаптивная реконструкция лендинга Snapbuild на React. В рамках работы была воспроизведена исходная страница, добавлены пять новых секций в общей стилистике сайта, реализованы интерактивные элементы, форма с валидацией, страницы ошибок и автоматическая публикация на GitHub Pages.

## Опубликованная страница

[https://arishkawolf.github.io/snapbuild-test-task-/](https://arishkawolf.github.io/snapbuild-test-task-/)

## Локальный запуск

Для запуска потребуется Node.js 22 или новее.

```bash
git clone https://github.com/ArishkaWolf/snapbuild-test-task-.git
cd snapbuild-test-task-
npm install
npm run dev
```

После запуска адрес локального сервера появится в терминале.

Дополнительные команды:

```bash
npm run build          # production-сборка
npm test               # однократный запуск тестов
npm run test:watch     # тесты в режиме наблюдения
npm run test:coverage  # тесты с отчётом покрытия
```

Для отправки формы необходимо скопировать `.env.example` в `.env` и указать адрес обработчика:

```env
VITE_CONTACT_ENDPOINT=https://example.com/api/contact
```

Без настроенного обработчика форма не показывает ложное сообщение об успехе, а предлагает связаться по электронной почте.

## Добавленные секции

В стилистике исходной страницы были разработаны пять дополнительных секций:

1. **Сценарии использования** — задачи платформы для маркетинга, дизайна, продаж и продукта.
2. **Результаты внедрения** — карточки с ключевыми показателями и преимуществами.
3. **Истории команд** — интерактивная карусель отзывов и результатов клиентов.
4. **Тарифы** — три варианта подключения и переключатель периода оплаты.
5. **Запросить демо** — контактная форма с проверкой введённых данных и обработкой ошибок отправки.

## Анализ стилистики исходного сайта

Перед разработкой я проанализировала визуальную систему исходной страницы: композицию и порядок блоков, размеры заголовков, типографическую иерархию, ширину контейнеров, отступы, скругления, цветовые переходы и контраст элементов. Отдельно изучила поведение навигации, карточек, кнопок, табов и горизонтальных блоков, а также изменения макета на разных размерах экрана.

На основании этого анализа были выделены повторяющиеся приёмы: светлый нейтральный фон, крупная типографика, чёрно-белые элементы управления, розово-персиковые градиенты, большие скругления и спокойные анимации. Новые секции проектировались с использованием тех же правил, чтобы они воспринимались как естественная часть исходного сайта.

## Что удалось воспроизвести

Удалось реализовать все основные части исходной страницы: шапку и навигацию, первый экран, блок логотипов, продуктовые карточки, интерактивную витрину форматов, сравнительную таблицу, блок безопасности, FAQ, дорожную карту и подвал. Также воспроизведены адаптивное поведение, градиенты, карточная сетка, состояния кнопок, табы, карусели и анимация появления секций.

Все запланированные элементы присутствуют и работают, хотя отдельные визуальные детали и анимации воспроизведены не на 100% идентично оригиналу.

## Что не удалось реализовать

Не удалось полностью воспроизвести оригинальное поведение скролла в блоке «Каждый день — новый релиз». Ранее я не работала с таймлайнами такого типа, поэтому реализовала собственный вариант горизонтального перемещения с поддержкой перетаскивания мышью и адаптацией для мобильных устройств.
